docs(changelog): write the release notes in Chinese

The generated notes shipped in English because the repository said so in
three places: the rules, the commit-msg hook and the parser warning. The
release page, the update dialog and the website all render the stored text
as typed, so the only copy a Chinese reader ever saw was English.

The trailer, the group headings and the empty-version note are Chinese now,
and the rules ask for Chinese copy instead of rejecting anything that is
not English. Entries whose wording changed keep pointing at the same
commit, so verify still derives every one of them.
